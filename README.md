# Python & Bash DevOps Assignment

## Project Structure
- `task1_grade_checker.py`: Evaluates numeric score into letter grades (A-F) using `if/elif/else`.
- `task2_student_grades.py`: Manages student names and grades using a Python dictionary with add, update, and display functionality.
- `task3_write_file.py`: Creates and writes text content to `sample_output.txt` using `open()` and `write()`.
- `task4_read_file.py`: Reads and prints content from `sample_output.txt` using `open()` and `read()`.
- `sample_output.txt`: Output file generated by Task 3 and read by Task 4.
- `Python_and_Bash_Assignment_Documentation.docx`: Full assignment documentation with terminal outputs and explanations.

## How to Run
```bash
python3 task1_grade_checker.py
python3 task2_student_grades.py
python3 task3_write_file.py
python3 task4_read_file.py
```
